# AgroMarket – Módulo Catálogo

Módulo de catálogo de productos para AgroMarket, la plataforma web de comercialización de productos agrícolas. Permite visualizar los productos disponibles con su precio referencial y filtrarlos por categoría (frutas, hortalizas, granos), como primer paso hacia la funcionalidad completa de búsqueda y compra del sistema.
